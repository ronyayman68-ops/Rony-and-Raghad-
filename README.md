# Neon Dodge

A fast-paced cyberpunk survival game built with HTML5 Canvas and JavaScript.

---

# 🎮 Gameplay

- Control the neon orb
- Dodge incoming enemies
- Survive as long as possible
- Use dash energy strategically
- Beat your high score

---

# ✨ Features

- Cyberpunk neon visuals
- Smooth animated HUD
- Dash system with energy ring
- Enemy variations
- Particle effects
- Mobile touch controls
- Android app support using Capacitor
- GitHub Pages web hosting

---

# 🕹 Controls

## Desktop

| Key | Action |
|------|--------|
| W A S D | Move |
| SPACE | Dash |
| ENTER | Start |
| R | Restart |

---

## Mobile

- Touch and drag to move
- Tap dash button to dash

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/ronyayman68-ops/Rony-and-Raghad-.git
```

## Open Project

```bash
cd Rony-and-Raghad-
```

## Install Capacitor

```bash
npm install
```

## Run Android

```bash
npx cap sync
npx cap open android
```
